# DSE Share Tracker — suhried.github.io/dse_share

GitHub Actions scrapes DSE + BullBD every 30 minutes and publishes data to GitHub Pages.

## Repo structure

```
dse_share/
├── scraper.py                  # Python script — runs in GitHub Actions
├── .github/
│   └── workflows/
│       └── scrape.yml          # Cron job definition
└── docs/
    ├── index.html              # Mobile-friendly dashboard
    └── output.json             # Auto-generated by scraper (don't edit)
```

## Setup (one-time)

### 1. Create the repo

Go to github.com → New repository → name it `dse_share` → Public → Create.

### 2. Push these files

```bash
cd dse_share
git init
git remote add origin https://github.com/suhried/dse_share.git
git add .
git commit -m "init"
git branch -M main
git push -u origin main
```

### 3. Enable GitHub Pages

Repo → Settings → Pages → Source: **Deploy from branch** → Branch: `main` → Folder: `/docs` → Save.

Your site will be live at: `https://suhried.github.io/dse_share`

### 4. Allow Actions to push commits

Repo → Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

### 5. Trigger first run manually

Repo → Actions → DSE Scraper → Run workflow → Run.

After ~2 minutes the page will have live data.

## Schedule

Runs at :00 and :30 of every hour (UTC). Since Bangladesh is UTC+6, that's every half hour through the day.

## Update portfolio

Edit `PORTFOLIO` in `scraper.py` and push — next cron run picks it up.
